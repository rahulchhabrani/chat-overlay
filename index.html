Chat Overlay

A Chrome extension that overlays Twitch, Kick & YouTube chat on any website — so you can read your stream chat while playing chess (or anything else).

↓ Download ZIP View on GitHub
Preview

Features
🖤
Twitch
Live chat via IRC WebSocket. No delays.
💚
Kick
Chat via Pusher WebSocket connection.
▶
YouTube
Live chat relayed via DOM bridge.
↔
Draggable
Drag, resize, collapse — put it anywhere.
◑
Dim mode
Transparent overlay so it never blocks your view.
📄
Persistent
Chat history survives page refreshes.
Install
1
Download the ZIP above and unzip it anywhere on your computer.
2
Open Chrome and go to chrome://extensions. Enable Developer Mode (toggle top right).
3
Click Load unpacked and select the unzipped folder.
4
Click the extension icon in your toolbar, enter your channel names, hit Save & Connect.
