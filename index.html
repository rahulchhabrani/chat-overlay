Install in 4 Steps
1
Download — click the button above and unzip the file
2
Open chrome://extensions and enable Developer mode (top-right toggle)
3
Click Load unpacked and select the unzipped chat-overlay-main folder
4
Click the Chat Overlay icon in your toolbar, enter your channel names, and hit Save & Connect
How to Use

Twitch & Kick

Enter your channel name in the popup and click Save & Connect. The overlay appears on whichever site you've set as the target (default: chess.com). Change the target site in the popup to any domain you want.


YouTube

Open the YouTube live stream in any Chrome tab. Chat messages from that stream will automatically appear in the overlay on your target site.


All three at once

You can run Twitch, Kick, and YouTube chat simultaneously. The colored dots in the overlay header show which platforms are live — purple for Twitch, green for Kick, red for YouTube.


Why does this work on strict sites like chess.com?

Most chat overlays use iframes, which get blocked by Content Security Policies. This extension uses direct WebSocket connections to each platform's native API — so it works everywhere.
