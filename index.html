Why this exists

"I didn't want to buy a second monitor just to read chat."

I stream on Twitch, Kick, and YouTube while playing chess on chess.com all on a single Mac. Reading chat meant glancing at my phone constantly: tiny text, wrong angle, and I'd lose focus mid-game. A second monitor felt like overkill for a problem that software could solve. So I built this floating overlay that keeps chat visible on whatever I'm doing, no second screen required.

1
Add to Chrome

Click Add to Chrome above to install from the Chrome Web Store — no zip, no Developer Mode needed.

2
Open the overlay

Click the Chat Overlay icon in your Chrome toolbar to open the popup.

3
Connect your channels

Click the Chat Overlay icon in your toolbar, enter your Twitch / Kick / YouTube channel, and hit Save & Connect.

Twitch
Native IRC

Connects directly to Twitch’s IRC over WebSocket. No login or OAuth token required.

Kick
Pusher WebSocket

Connects to Kick’s Pusher API in real time. Instant message delivery, no polling.

YouTube
DOM Relay

Reads chat from an open YouTube stream tab and relays it to the overlay automatically.

Why it works everywhere
No iframes

Most overlays use iframes which get blocked by strict CSPs. Direct WebSockets bypass that — works on chess.com, gaming sites, anywhere.
