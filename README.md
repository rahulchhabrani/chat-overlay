# chess-chat-overlay

Chrome extension — Daily Build #3

Overlays Twitch, Kick & YouTube chat on any website while you play chess (or any game). Native WebSocket connections, no iframes.

## Features
- Twitch chat via IRC WebSocket
- Kick chat via Pusher WebSocket  
- YouTube chat via DOM relay
- Draggable, resizable, collapsible overlay
- Transparent "dim" mode
- Chat history persists across page refreshes
- Configurable target website

## Install
1. Download and unzip
2. Open `chrome://extensions`, enable Developer Mode
3. Load unpacked → select the folder
4. Click the extension icon, enter your channel names, Save & Connect
