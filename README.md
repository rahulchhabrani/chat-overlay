# Chat Overlay – Twitch, Kick & YouTube

[![Chrome Web Store](https://img.shields.io/chrome-web-store/v/ckbekljbdfajcbomkmbcalhmbdfeonnc?label=Chrome%20Web%20Store)](https://chromewebstore.google.com/detail/chat-overlay-%E2%80%93-twitch-kic/ckbekljbdfajcbomkmbcalhmbdfeonnc)

Float Twitch, Kick, and YouTube chat on top of any website — without a second monitor or squinting at your phone. Native WebSocket connections, no iframes.

## Install

**[→ Add to Chrome (Chrome Web Store)](https://chromewebstore.google.com/detail/chat-overlay-%E2%80%93-twitch-kic/ckbekljbdfajcbomkmbcalhmbdfeonnc)**

Or install manually:
1. Download and unzip this repo
2. Open `chrome://extensions`, enable Developer Mode
3. Load unpacked → select the folder
4. Click the extension icon, enter your channel names, Save & Connect

## Features

- Twitch chat via IRC WebSocket
- Kick chat via Pusher WebSocket
- YouTube chat via DOM relay
- Draggable, resizable, collapsible overlay
- Transparent "dim" mode
- Chat history persists across page refreshes
- Configurable target website
